# Decisions taken while extracting (B1.2, #305)

1. **Location.** The two packages live in `shared-ui/` inside the aibus repo, with the layout the spec suggests, instead of a new repository. The 2026-11-14 decision asks for a separate semver repo that both aibus and the webapp consume. I did not create one: a new public repository under an owner or org I was not given is not mine to pick, and the packages have no aibus imports, so `git subtree split --prefix=shared-ui` gives the repo with history whenever it is created. Until then the webapp consumes tarballs (see the webapp check).
2. **Names.** `@sharedui/*`, neutral on purpose so neither product's name is in the API. Publishing the scope is a follow-up.
3. **Rewrite, not copy.** The webapp components use Tailwind classes, hard-coded hex and Kendo icons, so I wrote the primitives against tokens and kept the behaviour (props, roles, focus handling). The webapp's comments carry its own issue numbers, which would mislead here.
4. **Contrast re-picks.** The webapp's brand blue `#3584e4` is 3.9:1 under white text, so the primary fill is `#1A5FB4` in light (6.29:1 with white) and `#62A0EA` with navy text in dark (6.94:1). Danger is `#B91C1C` with white in light. The light input border is `#7D8BA1` (3.45:1 on white), because the first value I tried, `#8A97AB`, measured 2.96:1 and failed the 3:1 rule.
5. **Showcase.** A small Vite app (the aibus consumer) instead of Storybook: Storybook 10 is a large dependency tree to put under the licence gate, and the app is also the consumer smoke test. Revisit if the webapp's Storybook should show the shared components too.
6. **No data-grid package yet.** The decision says TanStack Table plus Virtual; nothing in B1.2's acceptance needs it, and B1.4 or later has the real use.
7. **Licence list.** MIT-0 added to the allowed list (one transitive of jsdom, strictly more permissive than MIT).
8. **Desktop app.** B1.1 (#304) is not merged and `desktop/` has no frontend yet, so the aibus consumer is the smoke app in `consumers/aibus-smoke`. When the desktop app lands, it adds `@sharedui/*` to its own `package.json` and drops the smoke app's role as the only consumer.
